# 科烽智能 AGV 月报生成工具（MonthlyReportGenerator）

Windows 桌面端：按天填写 AGV 项目工作月报，自动计算工时、加班、项目出勤与月度汇总，一键导出 **CSV / XLSX**（两者内容完全一致）。用于替代原网页版月报填写系统，仅供公司内部分发使用。

## 功能特性

- 整月明细自动生成（每天一行，含星期提示），上下班时间用"小时 + 分钟"下拉选择；
- **全自动计算**：工作时长、加班时长、项目出勤、六项月度汇总、项目地点汇总，无需手算；
- 支持地点规则：`公司` / `项目名` / `调休` / `休息` 及组合 `公司/项目名`、`调休/项目名`；
- 支持**跨午夜班次**（下班早于上班按 +24h 计算）；
- **法定节假日/补班日**支持：内置 2025/2026 年数据，其余年份启动时自动联网刷新（timor.tech）并本地缓存，断网时回退缓存或"仅周末"规则；
- 周末/法定节假日行红色高亮；时间输入聚焦时自动预填 09:00 / 17:00；
- 草稿按"年-月"自动保存，姓名/工程师等级跨月记忆；
- 导出：布局构建与产物输出解耦，CSV（UTF-8 带 BOM）与 XLSX（带样式）由同一布局构建器生成，**内容完全一致**，默认文件名 `AGV月报_{姓名}_{年}_{月}.{扩展名}`；
- 单文件发布（框架依赖），双击即运行，免安装。

## 业务规则（与张工网页版月报系统一致）

### 上班地点填写规则

| 填写内容 | 含义 |
|---|---|
| `公司` | 未出外勤，在公司上班（不计项目出勤，不出现在地点汇总） |
| `项目名`（如 `无锡国药`） | 全天外勤 |
| `公司/项目名` | 半天公司、半天外勤（项目出勤记 0.5，当天加班全归项目） |
| `调休` / `休息` | 工作日调休，不计出勤（两者同义） |
| `调休/项目名` | 混合：调休占 4 小时，工作超 4 小时部分计加班 |

### 自动计算规则

| 指标 | 规则 |
|---|---|
| 工作时长(h) | 下班 − 上班；跨午夜 +24h；保留 2 位小数 |
| 加班时长(h) | 周末/法定节假日（含补班的周末）→ 全部时长；工作日混合调休 → 超 4h 部分；其余工作日 → 超 8h 部分（8 小时制） |
| 项目出勤 | 纯调休/休息或"公司"→ 0；"公司/项目"→ 0.5；其余按工作时长：<4h→0、4~8h→0.5、≥8h→1 |
| 实际上班天数(天) | ≥8h 记 1、4~8h 记 0.5、<4h 记 0；排除纯调休/休息 |
| 项目出勤天数(天) | Σ(项目出勤) |
| 总工作时长 / 总加班时长(h) | Σ(工作时长) / Σ(加班时长) |
| 当月累计可调休天数(天) | 总加班 ÷ 8，保留 2 位小数 |
| 当月已调休天数(天) | 仅工作日统计：纯调休/休息 +1，混合调休 +0.5 |
| 项目地点汇总 | 取每行第一个项目名，出勤与加班全额计入；按项目名升序排列 |

## 环境要求

- **开发**：Windows 11、Visual Studio 2026（".NET 桌面开发"工作负载）、.NET 10 SDK；
- **运行**：Windows 11 + **.NET Desktop Runtime 10.x**（主版本必须为 10）。

## 构建与发布

```powershell
# 调试构建
dotnet build

# 单文件发布（框架依赖，产物约 16MB 的单个 exe）
dotnet publish -c Release -p:PublishSingleFile=true --self-contained false -o .\publish
```

- 产物：`publish\MonthlyReportGenerator.exe`，双击即运行；
- 安装 .NET Desktop Runtime 10；

## 本地数据存储

所有数据保存在 `%LocalAppData%\MonthlyReportGenerator\`：

| 文件 | 用途 |
|---|---|
| `profile.json` | 姓名、工程师等级（跨月记忆） |
| `draft-{年}-{月}.json` | 各月草稿（每 10 秒自动保存一次，切换月份/导出/关闭时保存） |
| `holidays-{年}.json` | 节假日数据缓存（网络刷新成功后写入） |

## 节假日数据说明

1. 2025/2026 年内置于 `Models\WorkCalendar.cs`；
2. 其他年份：启动及切换年份时尝试从 `https://timor.tech/api/holiday/year/{year}` 刷新并缓存；失败则回退本地缓存，无缓存时按"仅周六/周日"规则；
3. 内网无法访问该域名时，源码中手动补充 `WorkCalendar` 内置表。

## 回归验证

以原网页版生成的：`ExampleFiles\AGV月报_曹铮_2026_9.csv` 作为参考：录入该月数据（6 个工作日 + 1 天调休）后导出，六项汇总应等于 `6.0 / 6.00 / 52.68 / 12.68 / 1.58 / 1.0`，地点汇总为 `无锡国药 6.0 / 12.68`。
